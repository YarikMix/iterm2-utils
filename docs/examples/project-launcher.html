Проекты в нижней панели iTerm2

Статический пример с вымышленными названиями. В iTerm2 каждая кнопка открывает новую активную вкладку с login shell в папке проекта, в том же окне.

Проект AПроект B
~ %
Проект AПроект B

Повторный клик создаёт ещё одну вкладку. В узком окне используйте меню Profiles. Это иллюстрация, а не интерактивная панель; браузер установленной функции не нужен.
